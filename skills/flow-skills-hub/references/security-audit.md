# 安全审计指南（蒸馏自 SAIL V2 91 项风险目录 · pillar-labs/sail-skill 119★）

## 适用场景

对 AI/Agent 系统做安全 gap 评估、合规检查、安全路线图制定。

## 风险目录（9 大类 · 91 项精选）

### 1. 注入与提示攻击 (10 项)
- 提示注入（直接/间接）
- 工具参数注入
- 跨会话污染
- AGENTS.md 被恶意覆盖
- MCP 服务器返回恶意指令

### 2. 认证与授权 (12 项)
- 子代理沙箱越权（read-only 代理写入）
- API key 泄漏到日志
- MCP 工具权限过大
- workspace-write 被滥用
- `--yolo` 绕过审批
- 凭据硬编码在技能正文中

### 3. 数据保护 (10 项)
- 敏感信息写入 VERIFICATIONS/ 或 DECISIONS.md
- 上下文中的 PII 泄漏到第三方 API
- git commit 包含密钥
- 日志文件含用户数据

### 4. 依赖链 (8 项)
- 技能引用的外部脚本被篡改
- npx 安装的技能包含恶意代码
- MCP 服务器供应链攻击
- AGENTS.md 引用不存在的文件导致路径遍历

### 5. 模型行为 (10 项)
- 幻觉导致执行危险命令
- 规模化扇出（max_depth 过大）成本失控
- 生成可执行代码未沙箱化
- 子代理继承过宽权限

### 6. 沙箱与隔离 (8 项)
- 沙箱逃逸（写文件到工作区外）
- 子代理通过文件系统侧信道通信
- 临时文件未清理
- 符号链接绕过沙箱

### 7. 可观测性 (8 项)
- 无审计日志
- 子代理行为不可追溯
- 审批决策无记录
- 错误被静默吞掉

### 8. 合规与治理 (15 项)
- 无数据保留策略
- 跨境数据传输
- 用户同意未记录
- 模型版本与数据未版本化
- 安全事件无响应流程

### 9. 供应链与基础设施 (10 项)
- CI/CD 管道被污染
- 容器镜像未扫描
- Secrets 管理不当
- 网络出口无限制

## 审计输出格式

每项给：风险等级（Critical/High/Medium/Low）+ 现状 + 建议。
最后给优先级排序的修复清单（从 Critical 开始）。

## 与 flow 的联动

`flow powerup` 体检时可触发本审计。审计结果写入 `.flow/SECURITY-AUDIT.md`。
