## autoflow-codex 状态契约

本项目使用 `.flow/` 目录作为人机共享的持久化状态：

- `PRD.md` 需求唯一事实来源（改需求先改这里）
- `PLAN.md` 任务清单：`- [ ]` 未完成 / `- [x]` 已完成（必须附验证摘要）
- `PROGRESS.md` 追加式执行日志（只追加，不删改历史）
- `MEMORY.md` 跨会话记忆：教训与约定（保持精简）
- `VERIFICATIONS/` 验证证据，每任务一份
- `APPROVED` 计划审批印章（存在 = 计划已获批）

**规则：**

1. 处理任务前，先读 `PLAN.md` 与 `PROGRESS.md` 末尾重建上下文
2. 一次只做一个任务；完成必须有验证证据，否则不许勾选
3. 每完成一个任务：更新状态文件 + 一个干净 git 提交
4. 计划未审批（无 APPROVED 印章）时，拒绝执行实现类工作
